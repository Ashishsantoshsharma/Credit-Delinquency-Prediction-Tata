# # 💳 Credit Delinquency Prediction Model
### Tata Data Analytics & GenAI Virtual Experience Program

A machine learning project to predict credit delinquency using
Logistic Regression, built as part of the Tata Group Data Analytics
Virtual Experience.

- **Python** (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
- **Machine Learning** (Logistic Regression)
- **Google Colab
- **GenAI** (Tata iQ / GenAI tools)
- **PowerPoint & Word** (Business reporting)

---

## 🤖 Model Details

- **Model:** Logistic Regression (Binary Classification)
- **Target:** Predict whether a customer will become credit delinquent
- **Key Features:**
  - Credit Utilization
  - Debt-to-Income Ratio
  - Missed Payments
  - Total Missed Payments
  - Credit Score

---

## 📊 Evaluation Strategy

| Metric | Purpose |
|---|---|
| Accuracy | Overall correctness |
| Precision | Reduces false alarms |
| Recall | Captures risky customers |
| F1 Score | Balance of precision & recall |
| AUC-ROC | Overall model strength (target > 0.75) |

---

##  Why Logistic Regression?
- High interpretability — essential in financial services
- Transparent decision-making for compliance
- Efficient and scalable for real-time risk assessment
